# GFE

This repository contains a simple Python script `mouse_simulator.py` that can simulate human-like mouse movements and clicks. The script uses the `pyautogui` library.

## Usage
1. Install the dependencies:
   ```bash
   pip install pyautogui
   ```
2. Run the script:
   ```bash
   python mouse_simulator.py
   ```
   The script automatically moves the mouse to the middle of the screen width
   and one-fifteenth of the screen height, clicking at random intervals between
   1 and 299 seconds.

Press `Ctrl+C` to stop the script.
